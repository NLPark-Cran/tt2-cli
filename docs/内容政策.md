# 内容政策

?hub.tt2.li 托管网络为开发者提供免费的静态站点托管。使用即表示同意：

## 禁止内容

- 违反中华人民共和国法律法规及服务器所在地法律的内容
- 钓鱼、诈骗、恶意软件分发
- 侵犯知识产权的内容
- 成人、赌博、毒品相关
- 未经许可的代理/VPN 转发服务
- 加密货币挖矿页面

## 审查机制

所有部署由服务端「猹询码」Agent 自动审查；违规内容将被拒绝部署，重复违规的账号将被封禁。

## 举报

发现违规站点请邮件 abuse@tt2.li，附上站点 URL 与说明，我们会在 48 小时内处理。

## 免责

平台按现状提供免费服务，不承诺 SLA。站点内容由部署者负责。
