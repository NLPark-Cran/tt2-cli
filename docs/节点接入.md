# 赞助商节点接入指南

感谢你愿意为 ?hub.tt2.li 托管网络提供 VPS！

## 节点要求

- Debian 12/13（其他 systemd 发行版亦可，未测试）
- ≥1C1G，≥10G 磁盘，公网 IPv4
- 开放 80/443（证书签发与站点访问）与 22（控制面推送）

## 接入步骤

1. 把你要提供的后缀域名（如 `xxx.tt2.li` 或你自己的域名）的泛解析 `A` 记录指向节点 IP；
2. 在节点上以 root 执行（向运营索取控制面公钥）：

```bash
curl -fsSL https://cli.tt2.li/edge-bootstrap.sh | bash -s -- <控制面公钥的base64>
```

脚本会：安装 Caddy → 创建低权 `deploy` 用户 → 安装控制面公钥 → 配置 sudoers 白名单（仅放行 Caddy 片段安装/移除脚本）→ 配置 UFW。

3. 告知运营你的后缀域名与节点 IP，登记入 `nodes` 表即开始承接站点。

## 安全说明

- 控制面仅以 `deploy` 低权用户 SSH 登录，提权仅限两个固定脚本；
- 用户站点是纯静态文件，无解释器、无用户进程；
- 你可随时 `systemctl stop caddy` 暂停服务，或联系运营摘除节点。

## 退出

联系运营将节点置为 `disabled`，存量站点会被迁移后清空。
